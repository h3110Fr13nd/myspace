# Plan 2: Dynamic WYSIWYG Editor, Quartz Graph/TOC/Backlinks, Multi-User Blog Publishing & Admin IAM Console

**Document**: Plan 2 Master Index  
**Location**: `plan/initial/rough/2.md`  
**Status**: Architecture Plan & Feature Roadmap  
**Basis**: Grounded in `plan/initial/1.md`. Focuses on WYSIWYG Markdown authoring, dynamic Quartz graph/TOC/backlinks engine, multi-user blog publishing, an Admin IAM Control Console, multi-tenant subfolder delegation, and clean connection handling.

---

## Plan 2 Detailed Modules

### 1. [01 - WYSIWYG Authoring & Markdown Editor](2/01_wysiwyg_editor_and_authoring.md)
- **Features**: Visual WYSIWYG Markdown & MDX editor, live `[[wikilink]]` autocomplete popovers, drag-and-drop MinIO image uploads, frontmatter editing, publishing state controls (Draft / Published / Restricted).

### 2. [02 - Dynamic Quartz Features: Interactive Graph, TOC & Backlinks](2/02_dynamic_graph_toc_backlinks.md)
- **Features**: Interactive D3.js force-directed graph generated dynamically per user session (hiding restricted notes), auto-generated scroll-spy Table of Contents, automatic incoming backlinks ("Linked References") discovery, and instant search popover (`Cmd+K`).

### 3. [03 - Multi-User Blog Publishing & Vault Spaces](2/03_multiuser_blog_publishing.md)
- **Features**: Multi-tenant user spaces (`/blogs/[user_id]`), blog creation/drafting/publishing workflows, public vs. team vs. private visibility, RSS/Atom feed generation.

### 4. [04 - Admin IAM Control Console](2/04_admin_iam_console.md)
- **Features**: Admin UI panel (`/admin/permissions`) for managing resources, users, groups, and explicit OpenFGA Allow/Deny bindings; relationship tuple inspector; storage analytics.

### 5. [05 - Service Resilience & Fallback Cleanliness](2/05_resilient_error_handling_and_fallbacks.md)
- **Features**: Single-line connection logging when local OpenFGA / MinIO services are offline during dev mode.

### 6. [06 - Multi-Tenant User Storage Engine & Subfolder Permission Delegation](2/06_user_storage_and_folder_delegation.md)
- **Features**: Personal root folder ownership (`folder:user_<id>_root`), user-controlled MinIO S3 object paths, subfolder resource nodes, subfolder access delegation (`owner`, `editor`, `viewer`, `denied_viewer`), and automatic downward inheritance propagation via OpenFGA tuple-to-userset rules.
