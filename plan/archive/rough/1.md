## Executive Overview

This repository defines a modular, enterprise-ready, 100% open-source content workspace. It merges the conceptual strengths of **Quartz** (remark/rehype AST, wikilinks), **HuggingFace Research Templates** (Astro/MDX research widgets), and **JSON Canvas** (spatial knowledge boards) backed by a **Google Zanzibar-style fine-grained access control system (OpenFGA)**.

To keep the architecture maintainable, detailed specifications are broken down into dedicated modules under [`plan/initial/rough/1/`](1/).

---

## Detailed Plan Modules

### 1. [01 - System Architecture & Core Stack](1/01_architecture_and_stack.md)
- **Topics**: Astro SSR framework, `unified`/`remark`/`rehype` AST processing, HuggingFace MDX component library, zero-JS default rendering.
- **Pivot Options**: Next.js (App Router), SvelteKit, Remix.

### 2. [02 - PDF & Media Asset Pipeline](1/02_pdf_and_media_pipeline.md)
- **Topics**: MinIO private S3 asset storage, secure byte-range streaming proxy, client-side PDF.js rendering, embedded canvas PDF nodes, watermarking.
- **Pivot Options**: Ceph / Rook, SeaweedFS, Headless Server PDF rendering.

### 3. [03 - Authorization, ReBAC & Programmatic API](1/03_authorization_rebac_and_api.md)
- **Topics**: OpenFGA Zanzibar model, GCP IAM-style Allow/Deny inheritance, exception lists, REST/gRPC programmatic endpoints (`grant`, `revoke`, `check`).
- **Pivot Options**: SpiceDB, Cerbos (YAML policy-as-code), Permit.io / OPA Cedar.

### 4. [04 - Canvas, Sheets, Forms & Node Access Control](1/04_canvas_sheets_forms_nodes.md)
- **Topics**: JSON Canvas open specification, node-level permissions, FortuneSheet spreadsheet nodes, `@rjsf/core` dynamic JSON schema form nodes, server-side data filtering.
- **Pivot Options**: React Flow, tldraw Core, Univer, Luckysheet.

### 5. [05 - Local Environment Setup & Docker Compose](1/05_local_docker_environment.md)
- **Topics**: Complete local `docker-compose.yml`, Traefik V3, PostgreSQL, OpenFGA, MinIO, Meilisearch, developer quickstart commands.

### 6. [06 - Production Deployment Blueprint & DevOps](1/06_production_deployment_and_devops.md)
- **Topics**: Production architecture, Traefik SSL termination, database connection pooling (PgBouncer), WAL-G automated backups, non-root security, horizontal scaling.
- **Pivot Options**: Kubernetes (Helm), Docker Swarm, HashiCorp Nomad, Cloud Managed Postgres.

### 7. [07 - Identity Management & Permission-Aware Search](1/07_identity_and_search.md)
- **Topics**: Authentik / Keycloak OIDC authentication, user/group synchronization to OpenFGA, Meilisearch & PostgreSQL permission-aware search filtering.
- **Pivot Options**: Keycloak, Zitadel, Ory Kratos, Typesense, PostgreSQL FTS + pgvector.

### 8. [08 - Master Pivot Matrix & Architectural Decision Records](1/08_pivot_matrix_and_adrs.md)
- **Topics**: Executive decision matrix outlining triggers, fallback alternatives, migration complexity, and core Architectural Decision Records (ADRs).
