# Deep Reinforcement Learning Frameworks for Edge Optimization

Comprehensive benchmarks comparing discrete vs continuous DRL formulations across non-stationary wireless environments.

## Algorithm Feature Matrix

| DRL Algorithm | Action Space | Sample Efficiency | Convergence Speed | Stability |
| :--- | :--- | :--- | :--- | :--- |
| **DQN / Rainbow** | Discrete | High (Replay Buffer) | Moderate | Susceptible to Q-overestimation |
| **PPO** | Continuous & Discrete | Moderate (On-Policy) | Fast | Extremely Stable (Clipped Surrogate) |
| **DDPG** | Continuous | High | Slow | Sensitive to Hyperparameters |
| **SAC** | Continuous | Exceptional | Fast | Robust (Max Entropy Regularization) |
